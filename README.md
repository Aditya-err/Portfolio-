# G. Aditya Prasad Achary - Personal Portfolio

Welcome to my personal developer portfolio! This repository contains the source code for my premium, interactive, and AI-inspired portfolio website. It showcases my skills, professional journey, educational milestones, and projects with a modern, sleek, and highly animated dark-theme design.

## 🚀 Features

- **Premium Dark Aesthetics**: A stunning dark mode with glassmorphism (frosted glass) effects, vibrant accents, and complex multi-color radial and linear gradients.
- **Interactive System Engine**: Custom-built JavaScript engine that powers interactive nodes, particle systems, and continuous floating animations across different sections.
- **Dynamic Capabilities Map**: An engaging layout to showcase my technical skills, AI engineering, and development capabilities.
- **Cinematic Experience & Projects**: A customized modal system to preview projects, view codebase links, and explore my journey timeline seamlessly.
- **Responsive Design**: Fully responsive across mobile, tablet, and desktop viewports, ensuring a flawless user experience on any device.
- **Virtual Pitch Portal**: A built-in terminal-like UI that allows visitors to pitch ideas or reach out directly.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and layout.
- **CSS3 (Vanilla)**: Advanced CSS properties including Flexbox, CSS Grid, custom `@keyframes` animations, `backdrop-filter`, masking, and complex gradients.
- **JavaScript (Vanilla)**: High-performance DOM manipulation, `requestAnimationFrame` particle physics engines, dynamic DOM generation, and custom modal handling without relying on heavy external libraries.

## 📂 Project Structure

- `index.html` - The main entry point and structural markup of the portfolio.
- `styles.css` - The core stylesheet containing all the premium styling, layouts, and animations.
- `script.js` - The JavaScript file driving the interactive elements, physics-based animations, and dynamic content.
- `pdf/` - Directory containing assets such as vector SVGs (icons, background elements) and PDF certificates.

## ⚙️ Setup & Execution

Since this project is built using native web technologies, no complex build steps or dependencies are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aditya-err/Portfolio-.git
   ```
2. **Open the project:**
   Simply open the `index.html` file in your preferred modern web browser.
3. **Optional (Live Server):**
   If you are using VS Code, you can use the **Live Server** extension to launch a local development server for a better development experience.
